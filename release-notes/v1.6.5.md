# Bilitato v1.6.5

本次版本集中提升模型兼容、流式生成、字幕读取和故障诊断能力，并新增聊天推理强度选择。

## 新增

- 聊天页新增“自动 / 低 / 中 / 高”推理强度。默认使用“自动”，继续沿用插件内置模型规则。
- 新增版本化 `request_policies` 远程配置，可按 Provider、模型正则和任务类型调整推理参数。
- 新增模型请求元数据日志，记录任务、参数名、推理策略来源、匹配规则 ID 和最终推理强度。
- 新增字幕读取过程日志，覆盖检测、接收、解析、接受、去重和丢弃原因。
- 新增响应头、首个流事件、首个可见文字等请求耗时指标。

## 优化

- 保留本地模型能力规则作为默认行为；远程规则关闭、无匹配、版本不支持或内容非法时自动使用本地规则。
- `request_policies` 仅允许白名单任务、推理模式和参数传输方式，避免远程配置注入任意请求字段。
- 每次 ModelScope 备用模型切换后重新匹配推理策略，且模型回退继续严格限制在 ModelScope。
- 总结、分段和合并任务对明确支持的模型关闭思考或使用 `low`；聊天由用户选择；不支持相关参数的模型保持 `provider_default`。
- 更新 OpenAI、DeepSeek V4.1、Qwen、GLM、MiMo、Kimi、Gemini、Claude 和 OpenRouter 的模型能力匹配，并保留旧模型名称映射。
- 流式请求在收到内容后将读取期限延长至 90 秒；等待首包仍使用原有超时，避免无响应请求长期占用任务。
- 结构化输出改为先解析和校验，再根据实际完整性决定是否重试。
- 暂时隐藏“模型剩余”和“账号剩余”，保留耗时及 Token 指标；后台额度采集逻辑不变。
- 远程配置缓存可重新读取已规范化的 camelCase 数据，兼容插件重启后的缓存恢复。

## 修复

- 修复部分 B 站视频字幕入口延迟出现时未能读取字幕的问题。
- 修复同一字幕重复写入、分 P 路由事件导致字幕短暂消失或反复刷新的问题。
- 修复部分模型默认深度思考导致总结首包长时间没有正文的问题。
- 修复分段 JSON 已完整且覆盖字幕末尾，却因 `finish_reason: length` 被误判并重复生成的问题。
- 修复下载监听和请求头规则范围过宽、可能影响其他网站下载的问题。
- 修复验真返回空对象、空数组、代码块 JSON、字段别名或轻微格式错误时处理不准确的问题。
- 修复 ASR 连接、上传、等待结果和总任务超时分类不清，以及同一失败重复上报 Sentry 的问题。
- 修复 Firefox 页面节点瞬时变化产生大量非插件 DOM 异常的问题。
- 修复本地模型使用 `http://localhost` 或 `http://127.0.0.1` 时无法完成授权的问题；非本地 HTTP 地址仍会被拦截。

## 兼容性

- 老版本会忽略远程配置中的 `request_policies` 字段，不受新配置影响。
- 新版本仅接受 `schema_version: 1`；未知版本会禁用远程策略并回退本地规则。
- 支持的任务：`summary`、`segments`、`summary_segments_merged`、`rumors`、`chat`。
- 支持的模式：`provider_default`、`disabled`、`none`、`low`、`medium`、`high`。
